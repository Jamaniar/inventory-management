Factory Inventory Management System

A two-tier demo app. A Vue 3 single-page app talks over HTTP to a stateless FastAPI service, which serves sample data that it loads from JSON files into memory when it starts. There is no database, no authentication and no persistence layer.

Data flow: a filter change

What happens when a user picks a filter, such as Warehouse = Tokyo, on the Dashboard.

  1. The user changes a dropdown in FilterBar, which writes to a shared ref.
    components/FilterBar.vue → composables/useFilters.js (module-level refs, so every view sees the same state)
  2. The active view's watch() on the four filter refs fires and calls getCurrentFilters(), which maps Period to month and Location to warehouse.
    views/Dashboard.vue, around line 676
  3. api.js drops any filter set to 'all', builds a query string and sends the axios GET requests in parallel.
    GET /api/dashboard/summary?warehouse=Tokyo, /api/orders, /api/inventory, /api/backlog
  4. FastAPI runs apply_filters() and then filter_by_month() as list comprehensions over the in-memory lists.
    server/main.py. Inventory has no date, so it skips the month filter
  5. The response is validated against its Pydantic response_model and serialized to JSON.
    Summary and report endpoints return plain dicts with no model
  6. The view stores the raw arrays in refs (allOrders, inventoryItems), and computed properties derive the KPIs, chart series and table rows. Then the SVG charts re-render.
    Currency formatting goes through utils/currency.js with USD or JPY from useI18n

Known gaps found while reading the code

The frontend and backend have drifted apart in a few places.

Frontend calls endpoints that don't existapi.js defines /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, but main.py has no such routes. App.vue calls getTasks() on load, so that request returns 404.
Unregistered componentDashboard.vue renders <PurchaseOrderModal>, but no file or import exists for it, so Vue logs a "failed to resolve component" warning.
Orphaned viewviews/Backlog.vue exists but has no route in main.js.
Hardcoded configurationThe API base URL http://localhost:8001/api is hardcoded in api.js and again in Reports.vue. Quarter mapping only covers 2025 (QUARTER_MAP and the if/elif chain in /reports/quarterly).
Loose month matchingfilter_by_month uses a substring check (month in order_date) instead of a prefix match. It works with the current ISO dates but would be fragile with other formats.
